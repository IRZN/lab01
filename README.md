# Portfólio Profissional — LAB01S01

## Descrição

Desenvolvimento inicial de um website de portfólio profissional para apresentar a trajetória acadêmica, habilidades, projetos, experiências e informações de contato.

O projeto foi planejado para possuir uma interface moderna, acessível e responsiva, com conteúdo em português e inglês.

## Objetivos da Sprint 1

- Criar o repositório no GitHub.
- Elaborar wireframes de média fidelidade no Figma.
- Desenvolver o protótipo inicial do front-end.
- Implementar navegação entre as seções.
- Construir o layout principal com cabeçalho, conteúdo e rodapé.
- Documentar a estrutura e as tecnologias do projeto.

## Tecnologias previstas

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Lucide React
- Figma
- Git
- GitHub

## Funcionalidades do protótipo

- Navegação entre as seções.
- Apresentação pessoal em português e inglês.
- Seção de habilidades técnicas.
- Projetos organizados em linha do tempo.
- Seção de experiências acadêmicas e profissionais.
- Links para e-mail, GitHub, LinkedIn e WhatsApp.
- Menu adaptado para dispositivos móveis.
- Layout responsivo para diferentes tamanhos de tela.

O formulário funcional e o envio de mensagens serão implementados na Sprint 2. A hospedagem definitiva será realizada na Sprint 3.

## Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/portfolio-profissional.git
```

Acesse a pasta:

```bash
cd portfolio-profissional
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço apresentado pelo Vite, normalmente:

http://localhost:5173

## Build de produção

Para verificar se o projeto pode ser compilado:

```bash
npm run build
```

Para visualizar a versão compilada:

```bash
npm run preview
```
